# Changelog — ClaudeBlox

## v1.6.0 — 2026-02-25 — Analytics Agent + Pipeline Immune System

### Added
- **analytics agent**: pipeline immune system — reads all agent reports each cycle,
  separates signal from noise, diagnoses failures as TYPE 1 (prompt) / TYPE 2
  (context) / TYPE 3 (architecture), commissions targeted fixes through
  ai-developer (3-7 per cycle). Runs foreground between STEP 7 and STEP 8
  (record progress and next cycle) in the git version's pipeline numbering.
- **ANALYTICS PASS step** in Game Master pipeline (between STEP 7 and STEP 8)
- **AI-DEVELOPER via analytics rule** — ai-developer is called exclusively by
  analytics, never directly by Game Master after individual subagent calls
- **Agent reports directory** — each cycle creates `logs/cycle-NNN/reports/` at
  the start of STEP 1, and agents write structured reports there as the primary
  data source for analytics
- **patterns.md** at `analytics/patterns.md` — cross-cycle immune memory
  (WATCHING, CONFIRMED PATTERNS, RESOLVED PATTERNS sections)

### Changed
- **computer-player**: Pre-Session State Validation gate added before Round 1 —
  detects stale pre-completed game state (`levelComplete=true` from a prior
  session), prevents false quality gate passes, reports BLOCKED with frozen
  timestamp as evidence
- **computer-player report template**: added `Pre-session state: [fresh / stale]`
  to the WIN CONDITION VERIFICATION section
- **CLAUDE.md**: analytics added to Task tool subagents list in the CONTEXT section
- **CLAUDE.md**: STEP 1 now creates `logs/cycle-NNN/reports/` directory and
  passes `Report path:` to every agent call
- **CLAUDE.md**: STEP 7 now creates `logs/cycle-NNN/` directory for analytics
  to write `_analytics_summary.md`
- **README**: 20 → 21 specialized AI agents; analytics added to TESTING &
  PUBLISHING box and agent descriptions table; Analyst roadmap item marked done
